# 797. All Paths From Source to Target

## Описание задачи
Дан ориентированный ациклический граф (DAG) с `n` вершинами, пронумерованными от 0 до `n-1`, представленный в виде списка смежности `graph`, где `graph[i]` — массив вершин, достижимых из вершины `i`. Нужно найти все возможные пути от вершины 0 до вершины `n-1` и вернуть их в любом порядке.

**Пример 1**:
```
Input: graph = [[1,2],[3],[3],[]]
Output: [[0,1,3],[0,2,3]]
```

**Пример 2**:
```
Input: graph = [[4,3,1],[3,2,4],[3],[4],[]]
Output: [[0,4],[0,3,4],[0,1,3,4],[0,1,2,3,4],[0,1,4]]
```

**Ограничения**:
- `n == graph.length`
- `2 <= n <= 15`
- `graph[i][j] != i` (нет самопереходов).
- Все элементы `graph[i]` уникальны.
- Граф гарантированно ациклический.

## Алгоритм решения
Используем **глубинный поиск (DFS)** с возвратом (backtracking) для построения всех путей:
- Начинаем с вершины 0 и добавляем её в текущий путь.
- Рекурсивно обходим всех соседей текущей вершины.
- При достижении вершины `n-1` сохраняем текущий путь.
- После возврата из рекурсии удаляем последнюю вершину (backtracking), чтобы исследовать другие пути.

### Математическая основа
- Поскольку граф DAG, нет циклов, что позволяет использовать DFS без риска бесконечного цикла.
- Число путей зависит от структуры графа, но ограничено экспоненциальной сложностью из-за ветвления.

### Сложность
- **Время**: O(2^N) в худшем случае (например, полный граф), где N — число вершин.
- **Память**: O(N) для хранения текущего пути и стека рекурсии.
