# 1466. Reorder Routes to Make All Paths Lead to the City Zero

## Описание задачи
Дано дерево с `n` вершинами (0..n-1) и `n-1` ориентированными рёбрами, заданными массивом `connections`, где `connections[i] = [ai, bi]` — дорога от города `ai` к городу `bi`. Нужно переориентировать минимальное число рёбер так, чтобы из каждого города был путь к городу 0. Вернуть минимальное число рёбер, которые нужно переориентировать.

**Пример 1**:
```
Input: n = 6, connections = [[0,1],[1,3],[2,3],[4,0],[4,5]]
Output: 3
Explanation: Переориентировать рёбра [0,1], [1,3], [4,5].
```

**Пример 2**:
```
Input: n = 5, connections = [[1,0],[1,2],[3,2],[3,4]]
Output: 2
Explanation: Переориентировать рёбра [1,2], [3,4].
```

**Ограничения**:
- `2 <= n <= 5 * 10^4`
- `connections.length == n - 1`

## Алгоритм решения
Используем BFS для обхода дерева от вершины 0:
- Строим граф, храня для каждой вершины исходящие (`out`) и входящие (`in`) рёбра.
- Начинаем BFS с вершины 0.
- Для каждой вершины:
  - Если ребро исходящее (`node -> next`), его нужно переориентировать, увеличиваем счётчик.
  - Если ребро входящее (`node <- next`), переориентировать не нужно.
- Возвращаем количество переориентированных рёбер.


### Сложность
- **Время**: O(V + E) = O(n), так как E = V - 1 в дереве.
- **Память**: O(V + E) = O(n) для графа и очереди.

## Оптимизация
- Используем компактное представление графа: для каждой вершины храним только необходимые списки рёбер.
- BFS минимизирует количество операций.
- Массив `visited` и очередь занимают минимум памяти.
