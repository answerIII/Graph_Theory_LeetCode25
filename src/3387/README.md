# 3387. Maximize Amount After Two Days of Conversions

## Описание задачи
Дана начальная валюта `initialCurrency` (1.0 единицы), и два набора пар конвертаций: `pairs1` с курсами `rates1` для первого дня, `pairs2` с курсами `rates2` для второго дня. Каждая пара `[start, target]` позволяет конвертировать `start` в `target` с курсом `rate` и обратно с курсом `1/rate`. Нужно максимизировать количество `initialCurrency` после любых конвертаций за два дня.

**Пример 1**:
```
Input: initialCurrency = "EUR", pairs1 = [["EUR","USD"],["USD","JPY"]], rates1 = [2.0,3.0], pairs2 = [["JPY","USD"],["USD","CHF"],["CHF","EUR"]], rates2 = [4.0,5.0,6.0]
Output: 720.0
```

**Пример 2**:
```
Input: initialCurrency = "NGN", pairs1 = [["NGN","EUR"]], rates1 = [9.0], pairs2 = [["NGN","EUR"]], rates2 = [6.0]
Output: 1.5
```

**Ограничения**:
- `1 <= initialCurrency.length <= 3`
- `1 <= pairs1.length, pairs2.length <= 10`
- `1.0 <= rates1[i], rates2[i] <= 10.0`

## Алгоритм решения
Конвертации представляются как ориентированные графы. Используем модифицированный алгоритм Беллмана-Форда для поиска максимального множителя:
- День 1: находим максимальное количество каждой валюты, начиная с 1.0 `initialCurrency`.
- День 2: для каждой валюты из первого дня максимизируем количество `initialCurrency`.
- Используем логарифмы для преобразования умножения курсов в сложение, чтобы избежать проблем с точностью.

### Математическая основа
- Максимальный множитель эквивалентен поиску пути с максимальным произведением весов в графе.
- Логарифмы позволяют заменить умножение на сложение, что упрощает задачу.
- Поскольку нет циклов с положительным произведением (гарантировано условием), Беллман-Форд работает корректно.

### Сложность
- **Время**: O(V * E) для каждого дня, где V — число валют, E — число пар.
- **Память**: O(V + E) для хранения графа.
