# 886. Possible Bipartition

## Описание задачи
Дано `n` человек (от 1 до `n`) и массив `dislikes`, где `dislikes[i] = [ai, bi]` означает, что человек `ai` не любит человека `bi`. Нужно разделить всех людей на две группы (любой размер), чтобы люди, которые не любят друг друга, были в разных группах. Вернуть `true`, если это возможно, и `false`, если нет.

**Пример 1**:
```
Input: n = 4, dislikes = [[1,2],[1,3],[2,4]]
Output: true
Explanation: Группа 1: [1,4], Группа 2: [2,3].
```

**Пример 2**:
```
Input: n = 3, dislikes = [[1,2],[1,3],[2,3]]
Output: false
Explanation: Треугольник 1-2-3 не позволяет разделить на две группы.
```

**Ограничения**:
- `1 <= n <= 2000`
- `0 <= dislikes.length <= 10^4`
- `1 <= ai < bi <= n`

## Алгоритм решения
Проверяем, является ли граф двудольным, используя BFS:
- Строим граф в виде списка смежности.
- Используем массив `colors` для раскраски: 1 (группа 1), -1 (группа 2), 0 (не раскрашен).
- Для каждой компоненты связности:
  - Начинаем с нераскрашенной вершины, присваиваем ей цвет 1.
  - Используем BFS для раскраски соседей в противоположный цвет.
  - Если находим конфликт (соседи одного цвета), возвращаем `false`.
- Если конфликтов нет, возвращаем `true`.


### Сложность
- **Время**: O(V + E), где V — число вершин (`n`), E — число рёбер (`dislikes.length`).
- **Память**: O(V + E) для графа и массива раскраски.

## Оптимизация
- Используем список смежности для компактного хранения графа.
- BFS минимизирует количество операций.
- Массив `colors` хранит только необходимые данные.
