# 785. Is Graph Bipartite?

## Описание задачи
Дан неориентированный граф с `n` вершинами, представленный в виде списка смежности `graph`, где `graph[u]` — массив вершин, смежных с вершиной `u`. Нужно определить, является ли граф двудольным, то есть можно ли разделить вершины на два множества так, чтобы каждое ребро соединяло вершины из разных множеств.

**Пример 1**:
```
Input: graph = [[1,2,3],[0,2],[0,1,3],[0,2]]
Output: false
Explanation: Нельзя разделить вершины на два множества без конфликтов.
```

**Пример 2**:
```
Input: graph = [[1,3],[0,2],[1,3],[0,2]]
Output: true
Explanation: Можно разделить вершины на множества {0, 2} и {1, 3}.
```

**Ограничения**:
- `graph.length == n`
- `1 <= n <= 100`
- `0 <= graph[u].length < n`
- `graph[u]` не содержит `u` и дубликатов.
- Если `v` в `graph[u]`, то `u` в `graph[v]`.

## Алгоритм решения
Граф двудольный, если его можно покрасить в два цвета так, чтобы соседние вершины имели разные цвета. Используется **поиск в ширину (BFS)** для раскраски графа:
- Начинаем с непокрашенной вершины, красим её в цвет 0.
- Всех соседей красим в противоположный цвет (1).
- Продолжаем, переключая цвета.
- Если находим конфликт (соседние вершины одного цвета), граф не двудольный.
- Проверяем все компоненты связности, так как граф может быть несвязным.


### Математическая основа
- Граф двудольный, если в нём нет цикла нечётной длины.
- Раскраска в два цвета эквивалентна проверке отсутствия нечётных циклов.
- BFS гарантирует, что мы красим вершины слой за слоем, минимизируя конфликты.

### Сложность
- **Время**: O(V + E), где V — число вершин, E — число рёбер (проходим каждую вершину и ребро ровно один раз).
- **Память**: O(V) для хранения цветов и очереди.
