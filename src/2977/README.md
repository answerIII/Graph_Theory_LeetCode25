# 2977. Minimum Cost to Convert String II

## Описание задачи
Даны строки `source` и `target` длиной `n`, массивы `original`, `changed` и `cost`, где `cost[i]` — стоимость преобразования подстроки `original[i]` в `changed[i]`. В одну операцию можно заменить подстроку `x` в `source` на `y` с затратой `z`, если существует `j`, где `cost[j] = z`, `original[j] = x`, `changed[j] = y`. Операции должны быть либо непересекающимися, либо использовать одинаковые индексы. Найти минимальную стоимость преобразования `source` в `target` или вернуть `-1`, если это невозможно.

**Пример 1**:
```
Input: source = "abcd", target = "acbe", original = ["a","b","c","c","e","d"], changed = ["b","c","b","e","b","e"], cost = [2,5,5,1,2,20]
Output: 28
Explanation: Операции: b->c (5), c->e (1), e->b (2), d->e (20).
```

**Пример 2**:
```
Input: source = "abcdefgh", target = "acdeeghh", original = ["bcd","fgh","thh"], changed = ["cde","thh","ghh"], cost = [1,3,5]
Output: 9
```


**Ограничения**:
- `1 <= source.length == target.length <= 1000`
- `1 <= cost.length == original.length == changed.length <= 100`

## Алгоритм решения
- Собираем уникальные длины подстрок из `original`.
- Строим граф преобразований и используем Флойд-Уоршелл для минимальных стоимостей.
- DP: `dp[i]` — минимальная стоимость преобразования `source[0..i]` в `target[0..i]`.
  - Для каждой позиции `i` проверяем подстроки фиксированных длин, заканчивающиеся в `i`.


### Сложность
- **Время**: O(M³ + n * |lengths| * k), где M — число уникальных подстрок, |lengths| — число уникальных длин, k — число преобразований.
- **Память**: O(M² + n).

## Оптимизация
- Ограничиваем перебор подстрок только фиксированными длинами.
- Флойд-Уоршелл для цепочек преобразований.
