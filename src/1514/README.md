# 1514. Path with Maximum Probability

## Описание задачи
Дан неориентированный взвешенный граф с `n` вершинами (0..n-1). Рёбра заданы списком `edges`, где `edges[i] = [a, b]` — ребро между вершинами `a` и `b` с вероятностью успеха `succProb[i]`. Нужно найти путь от `start_node` до `end_node` с максимальной вероятностью успеха (вероятности перемножаются). Если пути нет, вернуть 0.

**Пример 1**:

```
Input: n = 3, edges = [[0,1],[1,2],[0,2]], succProb = [0.5,0.5,0.2], start = 0, end = 2
Output: 0.25
Explanation: Путь 0->2: 0.2; путь 0->1->2: 0.5 * 0.5 = 0.25.
```

**Пример 2**:
```
Input: n = 3, edges = [[0,1],[1,2],[0,2]], succProb = [0.5,0.5,0.3], start = 0, end = 2
Output: 0.3
```

**Ограничения**:
- `2 <= n <= 10^4`
- `0 <= start, end < n`
- `0 <= succProb[i] <= 1`

## Алгоритм решения
Используем алгоритм Дейкстры для поиска пути с максимальной вероятностью:
- Строим граф в виде списка смежности.
- Используем приоритетную очередь для выбора вершины с максимальной текущей вероятностью.
- Напрямую сравниваем вероятности, избегая логарифмов.
- Если пути до `end_node` нет, возвращаем 0.


### Математическая основа
- Вероятности перемножаются, значит, максимизация произведения эквивалентна максимизации суммы логарифмов.
- Поскольку `0 < prob <= 1`, `-log(prob)` ≥ 0, и мы минимизируем сумму `-log(prob)`.

### Сложность
- **Время**: O((V + E) * log(V)) с приоритетной очередью.
- **Память**: O(V + E) для графа и очереди.

## Оптимизация
- Используем BFS вместо Дейкстры, чтобы гарантировать нахождение пути с максимальной вероятностью.
- Напрямую сравниваем вероятности, избегая логарифмов.

### Алгоритм решения
Используем BFS для поиска пути с максимальной вероятностью:
- Строим граф в виде списка смежности.
- Используем очередь для перебора всех вершин.
- Обновляем вероятности для каждой вершины, если находим лучший путь.
- Если пути до `end_node` нет, возвращаем 0.
