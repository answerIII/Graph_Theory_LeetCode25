# 1591. Strange Printer II

## Описание задачи
Дан двумерный массив `targetGrid` размером `m x n`, где `targetGrid[row][col]` — цвет в позиции `row, col)`. Принтер печатает сплошные прямоугольники одного цвета, перекрывая существующие цвета, и каждый цвет можно использовать только один раз. Нужно определить, возможно ли напечатать `targetGrid`.

**Пример 1**:
```
Input: targetGrid = [[1,1,1,1],[1,2,2,1],[1,2,2,1],[1,1,1,1]]
Output: true
```

**Пример 2**:
```
Input: targetGrid = [[1,1,1,1],[1,1,3,3],[1,1,3,4],[5,5,1,4]]
Output: true
```


**Пример 3**:
```
Input: targetGrid = [[1,2,1],[2,1,2],[1,2,1]]
Output: false
```

## Математическая основа
Задача сводится к построению графа зависимостей между цветами и проверке на наличие цикла.

- Для каждого цвета c1  находим минимальный прямоугольник, содержащий все его вхождения.
- Если в этом прямоугольнике есть цвет c2 >= c1 , то c2  должен быть напечатан раньше c1  зависимость c2 => c1 .
- Строим ориентированный граф: вершины — цвета, рёбра — зависимости.
- Если в графе есть цикл, напечатать невозможно, так как цвета зависят друг от друга.

Проверку цикла выполняем с помощью топологической сортировки.

**Ограничения**:
- `1 ≤ m, n ≤ 60`
- `1 ≤ targetGrid[row][col] ≤ 60`


## Алгоритм решения
1. Находим минимальный прямоугольник для каждого цвета.
2. Строим зависимости: для каждого цвета c1  находим цвета c2 , которые находятся внутри его прямоугольника c2  должен быть напечатан раньше c1 .
3. Используем топологическую сортировку с очередью, чтобы проверить, можно ли напечатать все цвета.

### Сложность
- **Время**: O(m * n) для поиска прямоугольников + O(m * n * C) для построения зависимостей + O(C + E) для топологической сортировки, где C ≤ 60, E ≤ C². Итог: O(m * n).
- **Память**: O(C) для `colorBounds` и `dependencies`, O(C²) для `dependents`. Итог: O(1).
