# 3123. Find Edges in Shortest Paths

## Описание задачи
Дан неориентированный взвешенный граф с `n` вершинами (0..n-1) и `m` рёбрами, заданными массивом `edges`, где `edges[i] = [ai, bi, wi]` — ребро между `ai` и `bi` с весом `wi`. Нужно найти все кратчайшие пути от вершины 0 до вершины `n-1` и вернуть массив `answer`, где `answer[i] = true`, если ребро `edges[i]` входит хотя бы в один кратчайший путь, и `false` в противном случае.

**Пример 1**:
```
Input: n = 6, edges = [[0,1,4],[0,2,1],[1,3,2],[1,4,3],[1,5,1],[2,3,1],[3,5,3],[4,5,2]]
Output: [true,true,true,false,true,true,true,false]
```

**Пример 2**:
```
Input: n = 4, edges = [[2,0,1],[0,1,1],[0,3,4],[3,2,2]]
Output: [true,false,false,true]
```


**Ограничения**:
- `2 <= n <= 5 * 10^4`
- `m == edges.length`
- `1 <= m <= min(5 * 10^4, n * (n - 1) / 2)`
- `1 <= wi <= 10^5`

## Алгоритм решения
Используем один проход Дейкстры и BFS:
- Строим граф в виде списка смежности.
- Находим кратчайшие расстояния от вершины 0 до всех вершин с помощью Дейкстры, одновременно строя DAG кратчайших путей (храним предшественников).
- Используем BFS от вершины `n-1`, чтобы пройти по DAG и пометить рёбра, входящие в кратчайшие пути.


### Сложность
- **Время**: O((n + m) * log(n)) для Дейкстры + O(n + m) для BFS. Итог: O((n + m) * log(n)).
- **Память**: O(n + m) для графа, `dist`, `parents` и `edgeMap`.

## Оптимизация
- Один проход Дейкстры вместо двух.
- Компактное хранение графа (список смежности).
- Используем `Set` в `parents` для минимизации дублирования.
