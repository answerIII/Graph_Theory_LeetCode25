# 399. Evaluate Division

## Описание задачи
Даны уравнения вида `Ai / Bi = values[i]`, где `Ai` и `Bi` — строки (переменные), а `values[i]` — число с плавающей точкой. Также даны запросы `queries[j] = [Cj, Dj]`, для которых нужно вычислить `Cj / Dj`. Если результат неопределён, возвращается `-1.0`. Если переменная не встречалась, ответ также `-1.0`. Для `x / x` возвращается `1.0`, если `x` существует.

**Пример**:
```
Input: equations = [["a","b"],["b","c"]], values = [2.0,3.0], queries = [["a","c"],["b","a"],["a","e"],["a","a"],["x","x"]]
Output: [6.0,0.5,-1.0,1.0,-1.0]
```

**Ограничения**:
- 1 <= equations.length <= 20
- 0.0 < values[i] <= 20.0
- 1 <= queries.length <= 20
- `Ai`, `Bi`, `Cj`, `Dj` — строки из строчных букв и цифр.

## Алгоритм решения
Уравнения интерпретируются как взвешенный ориентированный граф, где:
- Вершины — переменные (`Ai`, `Bi`).
- Рёбра — значения деления (`Ai / Bi = k` даёт ребро `Ai -> Bi` с весом `k` и `Bi -> Ai` с весом `1/k`).
- Запрос `Cj / Dj` решается поиском пути от `Cj` к `Dj`, перемножая веса рёбер.

Используется **поиск в глубину (DFS)** для нахождения пути и вычисления произведения весов.

### Математическая основа
Для уравнений `a / b = k1`, `b / c = k2`:
- `a / c = (a / b) * (b / c) = k1 * k2`.
- Если путь от `a` к `c` существует, результат — произведение весов рёбер.
- Если пути нет, результат неопределён (`-1.0`).

### Сложность
- **Время**:
  - Построение графа: O(E), где E — число уравнений.
  - Обработка запросов: O(Q * V) в худшем случае, где Q — число запросов, V — число вершин.
  - Итог: O(E + Q * V).
- **Память**: O(V + E) для хранения графа и множества посещённых вершин.
