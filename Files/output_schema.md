# Output Format Specification

Данный документ описывает структуру и цели файлов .csv, необходимых для дальнейшего анализа работы реализованных алгоритмов.

---

## 📁 01_general_properties.csv

### Описание:
Основные характеристики графа: число вершин, рёбер, плотность, компоненты связности.

### Содержание:

| Column Name              | Type   | Description                                                                 |
|--------------------------|--------|-----------------------------------------------------------------------------|
| graph_id                 | string | Название файла, который содержит граф                                      |
| directed                 | int    | 0 = неориентированный, 1 = ориентированный                                 |
| num_vertices             | int    | Число вершин в графе                                                       |
| num_edges                | int    | Число рёбер в графе                                                        |
| density                  | float  | Плотность рёбер: num_edges / max_possible_edges                            |
| weak_comp_count          | int    | Число слабосвязных компонент                                               |
| weak_largest_comp_size   | int    | Размер максимальной слабосвязной компоненты (в вершинах)                   |
| weak_largest_comp_frac   | float  | Доля вершин в наибольшей слабой компоненте: weak_largest_comp_size / num_vertices |
| strong_comp_count        | int    | число сильносвязных компонент                                              |
| strong_largest_comp_frac | float  | Доля вершин в наибольшей сильной компоненте                                |


## 📁 02a_double_sweep.csv

### Описание:
Результаты двойного BFS-прохода: оценка диаметра и 90-процентиля для случайных узлов.

### Содержание:

| Column Name      | Type   | Description                                                                 |
|------------------|--------|-----------------------------------------------------------------------------|
| graph_id         | string | Название файла, содержащего граф                                           |
| seed_node        | int    | Стартовая вершина для первого BFS                                          |
| farthest_node    | int    | Узел, найденный на максимальном расстоянии от seed_node                    |
| diameter_est     | int    | Эксцентриситет второго прохода BFS (оценка диаметра графа)                 |


## 📁 02b_random_sample.csv

### Описание:
Статистика расстояний между 500/1000 случайно выбранными парами узлов из слабосвязной компоненты.

### Содержание:

| Column Name   | Type   | Description                                                                 |
|---------------|--------|-----------------------------------------------------------------------------|
| graph_id      | string | Название файла, содержащего граф                                           |
| sample_size   | int    | Размер выборки (500 или 1000)                                              |
| seed          | int    | Стартовая точка для генератора псевдослучайных чисел                       |
| num_pairs     | int    | Всего пар                                               |
| mean_dist     | float  | Среднее расстояние среди выборки                                           |
| median_dist   | float  | Медиана расстояний                                                        |
| p90_dist      | float  | 90-й процентиль расстояний                                                 |
| max_dist      | float  | Максимальное из измеренных расстояний (оценка диаметра)                    |


## 📁 02c_snowball.csv

### Описание:
Оценки расстояний на подграфе, построенном методом "снежного кома".

### Содержание:

| Column Name   | Type   | Description                                                                 |
|---------------|--------|-----------------------------------------------------------------------------|
| graph_id      | string | Название файла, содержащего граф                                           |
| init_size     | int    | Число стартовых вершин (2 или 3)                                           |
| target_size   | int    | Целевой размер выборки (500 или 1000)                                      |
| seed          | int    | Стартовая точка для генератора псевдослучайных чисел                       |
| num_pairs     | int    | Число измеренных пар (≈ target_size·(target_size–1)/2)                     |
| mean_dist     | float  | Среднее расстояние среди выборки                                           |
| median_dist   | float  | Медиана расстояний                                                         |
| p90_dist      | float  | 90-й процентиль расстояний                                                 |
| max_dist      | float  | Максимальное измеренное расстояние (оценка диаметра)                       |

## 📁 03_clustering_overview.csv

### Описание:
Число треугольников, глобальный и средний кластерные коэффициенты.

### Содержание:

| Column Name            | Type   | Description                                                                 |
|------------------------|--------|-----------------------------------------------------------------------------|
| graph_id               | string | Название файла, содержащего граф                                           |
| num_triangles          | int    | Общее число полных подграфов на 3 вершинах                                 |
| global_clustering_coef | float  | Транзитивность сети (глобальный коэффициент кластеризации)                 |
| avg_clustering_coef    | float  | Средний local-коэффициент кластеризации                                    |


## 📁 04_local_clustering.csv

### Описание:
Средний локальный кластерный коэффициент для наибольшей слабой компоненты.

### Содержание:
| Column Name               | Type   | Description                                                                 |
|---------------------------|--------|-----------------------------------------------------------------------------|
| graph_id                  | string | Название файла, содержащего граф                                           |
| node_id                   | int    | Идентификатор узла                                                         |
| degree                    | int    | Степень узла (количество соседей)                                          |
| num_edges_between_neigh   | int    | Число рёбер в подграфе соседей                                             |
| local_clustering_coef     | float  | Локальный коэффициент кластеризации: (2·num_edges_between_neigh)/(degree·(degree–1)) |


## 📁 05_degree_distribution.csv

### Описание:
Мин/макс/средняя степень, распределение степеней вершин.

### Содержание:

| Column Name   | Type   | Description                                                                 |
|---------------|--------|-----------------------------------------------------------------------------|
| graph_id      | string | Название файла, содержащего граф                                           |
| degree_k      | int    | Степень узлов (значение k)                                                 |
| count_nodes   | int    | Количество узлов, имеющих степень k                                        |
| probability   | float  | Вероятность степени                            |
| log_k         | float  | Логарифм степени: log₁₀(k)                                                 |
| log_prob      | float  | Логарифм вероятности: log₁₀(probability)                                   |


## 📁 06_robustness.csv

### Описание:
Изменение размера наибольшей слабой компоненты при удалении x% узлов.

### Содержание:

| Column Name        | Type   | Description                                                                 |
|--------------------|--------|-----------------------------------------------------------------------------|
| graph_id           | string | Название файла, содержащего граф                                            |
| removal_method     | string | Стратегия удаления: "random" (случайная) или "targeted" (целевая)           |
| x_percent          | float  | Процент удалённых узлов (0–100)                                             |
| run_id             | int    | Номер прогона                                                               |
| remaining_nodes    | int    | Количество оставшихся вершин                                                |
| largest_comp_frac  | float  | Доля вершин в наибольшей слабой компоненте связности после удаления         |


## 📁 07_algorithms_runtime.csv

### Описание:
Время выполнения каждого алгоритма с указанием параметров и типа расчёта.

### Содержание:

| Column Name               | Type      | Description                                                                |
|---------------------------|-----------|----------------------------------------------------------------------------|
| graph_id                  | string    | Название файла, содержащего граф                                           |
| algorithm                 | string    | Step or method (e.g., `double_sweep_bfs`, `compute_triangles`)             |
| params                    | string    | Any parameters like `seed=42`, `sample_size=1000`                          |
| run_id                    | int       | Номер прогона                                                              |
| start_timestamp           | timestamp | Время старта в формате ISO 8601 (YYYY-MM-DDThh:mm:ss)                      |
| elapsed_ms                | int       | Время выполнения в миллисекундах                                           |
| memory_used_mb            | float     | Потребление памяти в мегабайтах (пиковое/среднее)                          |
